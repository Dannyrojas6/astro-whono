# 1. 初次开机

- 一路跳过，直到出现联网界面
- 不要联网，按下键盘组合键**shift+F10**，然后在弹出界面中输入**oobe/bypassnro**并按**Enter**确认，此时会自动重启。如果使用该命令没有起效，则输入 `start ms-cxh:localonly` 来创建一个本地账户并直接进入系统，不需要重启。
- 重启过后依旧跳过，出现联网界面点击**我没有Internet连接**，然后点击继续
- 当需要输入姓名时，使用英文。密码不输，直接跳过，之后等待一会儿便开机进入系统

# 2. 进入桌面

- 连接外置存储设备，将图吧工具箱安装到电脑上
- 使用**DIskInfo**查看硬盘通电次数与通电时间，过长过多则可能为二手机或摸摸机
- 先用**AIDA64**对CPU进行FPU单烤，后面再打开**Furmark2**进行双烤，期间关注机器功耗与温度，也可选用工具箱已设定好的一键双烤模式
- 若单烤与双烤期间机器无异常状况，则视为安全下车，可联网进行使用

# 3. 系统优化

- 对硬盘进行分盘，除系统之外再分个D盘，用于与系统盘分割，避免出现需要格式化系统盘时，重要数据被连带一起删除，当然也可以再分多几个盘
- 使用 `irm https://get.activated.win | iex` 进行激活office和Windows
- 将WindowsDefender实时保护以及附带项全部关闭，否则会导致无法安装非正版软件，以及各种开源工具。如果自己不乱安装来历不明的软件，也可使用工具将WindowsDefender彻底删除。
- 注册Microsoft账号并登入系统以及Edge浏览器，可使用邮箱或者电话号码注册。
