正常来说，CPU频率越高，与硬件通信速度越快，性能越强。

但这是理论极限性能，绝大部分情况下，CPU占用率不会很高，甚至于常年处于低占用状态。

那么睿频所带来的极限性能提升收益并不高，且伴随着频率冲高，电压一定会增大，整体的温度和功耗暴涨，长期以往会极大的影响CPU寿命。

这也是为什么那一年生产的AMD芯片损坏概率如此之大。

原因在于AMD想通过睿频来强行提升CPU极限性能，弥补自己在芯片迭代上性能提升微弱的不足，代价却是消费者使用短短几年后就不得不额外花钱进行维修甚至更换，这招太败坏路人缘了。

但次年以及后续产品好像就没出现过这种问题，当然也可能是幸存者偏差。

为此进行了以下测试：

| 游戏名        | 分辨率      | 画面设置               | 游玩感受                                                                                  |
| ---------- | -------- | ------------------ | ------------------------------------------------------------------------------------- |
| 极品飞车22     | 4K       | 除分辨率，其他与2K游玩时设置相同  | 除了城区比赛时车辆过多，渲染压力大而导致的轻微掉帧，其他情况均和2K时游玩无异                                               |
| 我的世界：亡者世界  | 4K       | 除分辨率，其他与2K游玩时设置相同  | 首次进入世界时帧率非常低，且恢复到正常水平所需时间变长，但稳定后与2K时游玩无异                                              |
| The Alters | 4K30     | 4K全低+AMD FSR3不开帧生成 | 只能跑30帧，而且只支持最新的DLSS4，老显卡被迫使用FSR3，但即使是4K最低画质，渲染效果也跟2K高画质差不多，排除主观感受存在的误判，4K画质下的画面细节确实不错 |
| Palworld   | 4K60     | 4K60自定义中等画质        | 4K60和1080P60没太大差别，一开始会有一阵子的莫名卡顿，后续能稳定60运行，温度也控制在80°左右                                 |
| FGO        | 1920x864 | MuMu中性能+超宽屏        | 启动慢了不少，多开最多两个，否则第三个会特别卡，但此现象之前也存在，游玩过程未感知明显卡顿                                         |

不难发现，绝大部分游戏场景均无明显性能衰减问题，只有安卓模拟器这类对CPU硬件开销非常大，在启动时会出现加载过慢的现象，当然这几组测试还不足以说明睿频对绝大部分使用场景影响不大，可以继续追加其他游戏的测试，让结论更加可靠。

最关键的是，关闭睿频能大幅降低CPU温度，好像有一块隐形的温度墙，即使高负载环境下温度不会超过80°，只有极少数情况下，比如在CachyOS+Niri玩深海迷航2，渲染着色器的过程中会突破限制，温度能达到91°，但也没顶到95°温度墙。
